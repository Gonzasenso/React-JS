# 🎮 Gamerxtreme Ecommerce

Aplicación web de e-commerce desarrollada con **React** y **Firebase**, creada como proyecto final del curso de React. Permite navegar por un catálogo de productos, filtrarlos por categorías, visualizar su detalle y gestionar un carrito de compras con persistencia en Firestore.

## 🚀 Demo

🔗 https://gonzasenso.github.io/Gamerxtreme-Ecommerce/

---

## 📸 Características

- Catálogo dinámico de productos.
- Filtrado por categorías.
- Vista de detalle de cada producto.
- Carrito de compras.
- Cálculo automático del total.
- Generación de órdenes de compra.
- Integración con Firebase Firestore.
- Diseño responsive para dispositivos móviles y escritorio.

---

## 🛠️ Tecnologías utilizadas

- React
- React Router DOM
- Firebase
- Firestore Database
- Bootstrap
- CSS3
- Vite
